# Объекты и задачи

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + TypeScript, TanStack Query/Table, React Hook Form + Zod, React Router + Suspense, shadcn/ui, Redux Toolkit. Архитектура FSD. Supabase Auth/PostgreSQL с RLS и транзакционными RPC.

## Users

Постановщики строительной компании управляют стройками и поручениями. Исполнители работают со своими задачами и передают результат на проверку.

## Capabilities and Constraints

Вход, объекты, карточки объектов, задачи, история, мои задачи. Строгая схема переходов из пользовательского ТЗ. Настоящие аккаунты и данные в Supabase; закрытая регистрация, защита прав и истории в базе, контроль версий. Для проверки загружены демонстрационные объекты и задачи; локальный mock сохранён для изолированных тестов.

## Open decisions

Рабочее название «Контур» выбрано для шаблона. Допущения по удалению и переназначению записаны в README.

## Brand Commitments

Пользователь выбрал визуальное направление по предоставленному скриншоту CRM: светлые поверхности, холодный серый фон, синие акценты, мягкие тени и геометричный шрифт. Референс используется для оформления существующих экранов и не расширяет функциональные требования.
